Why Headless Migration uses "Migration DWD" instead of existing Okta SSO providers:

                  

                    Existing Okta providers (like oidc-okta or okta-saml) require each individual end-user to enter their password & 2FA in a browser. For an automated migration tool to back up and restore all users' private notebooks, datastores, and custom agents headlessly, GCP Workforce Identity Federation uses a federated Domain-Wide Delegation provider (migration-dwd-provider) with local RSA keys.
